# Three profile designs

Each option has the same working links, local graphics, coding-time table, blog feed, and contribution snake. All three support light and dark mode.

| Option | Character | Preview |
| :--- | :--- | :--- |
| Editorial | Slate and teal, compact project grid, clear section hierarchy. The recommended default. | [View Editorial](editorial/README.md) |
| Terminal | Green accents, monospace header, slash-prefixed sections, full-width project descriptions. | [View Terminal](terminal/README.md) |
| Workshop | Warm paper and copper colors, serif header, conversational copy, full-width projects. | [View Workshop](workshop/README.md) |

To switch the root README, change `design` in `profile.json` and regenerate. See [maintenance](../MAINTENANCE.md).
